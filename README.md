### 4. Wait & Feedback

영상에서는 깊게 다루지 않았지만, 앞으로 프로젝트를 진행하는 데 있어서 한 번의 프롬프트로는 항상 좋은 결과를 만들 수 없습니다.

AI가 수행한 명령의 결과로 **무엇이 어떻게 왜** 바뀌었는지 설명할 수 있어야 합니다.

모르는 부분은 추가 학습하거나 AI가 아닌 **본인의 의견**을 덧붙여서 피드백을 주면 더 좋은 방향으로 발전 가능성이 있습니다.
